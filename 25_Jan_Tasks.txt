## 💻 All Commands Executed (Windows PowerShell)

### **1. Project Initialization**

```powershell
# Create main directory
mkdir reqify
cd reqify

# Initialize Git
git init
git branch -M main
```

---

### **2. Frontend Setup (React + Vite + Tailwind)**

```powershell
# Create React app with Vite
npm create vite@latest frontend -- --template react

# Navigate to frontend
cd frontend

# Install base dependencies
npm install

# Install routing and HTTP client
npm install react-router-dom axios

# Install UI libraries
npm install lucide-react framer-motion

# Install Tailwind CSS (Fixed versions that work)
npm install -D tailwindcss@3.4.1 postcss@8.4.35 autoprefixer@10.4.18

# Initialize Tailwind
npx tailwindcss init -p

# Create folder structure
New-Item -ItemType Directory -Path "src\components\landing" -Force
New-Item -ItemType Directory -Path "src\components\dashboard" -Force
New-Item -ItemType Directory -Path "src\components\auth" -Force
New-Item -ItemType Directory -Path "src\components\common" -Force
New-Item -ItemType Directory -Path "src\pages" -Force
New-Item -ItemType Directory -Path "src\context" -Force
New-Item -ItemType Directory -Path "src\services" -Force
New-Item -ItemType Directory -Path "src\utils" -Force
New-Item -ItemType Directory -Path "src\hooks" -Force
New-Item -ItemType Directory -Path "src\styles" -Force
New-Item -ItemType Directory -Path "src\assets\images" -Force

# Create environment files
New-Item .env.example -ItemType File
Copy-Item .env.example .env

# Update package.json scripts
npm pkg set scripts.dev="vite"
npm pkg set scripts.build="vite build"
npm pkg set scripts.preview="vite preview"

cd ..
```

### **3. Backend Setup (Node.js + Express + MongoDB)**

```powershell
# Create backend directory structure
mkdir backend
mkdir backend\src
mkdir backend\src\config
mkdir backend\src\models
mkdir backend\src\controllers
mkdir backend\src\routes
mkdir backend\src\middleware
mkdir backend\src\services
mkdir backend\src\utils
mkdir backend\uploads
mkdir backend\uploads\temp
mkdir backend\logs
mkdir backend\tests

cd backend

# Initialize npm
npm init -y

# Install core dependencies
npm install express mongoose dotenv cors

# Install authentication
npm install jsonwebtoken bcryptjs

# Install file upload & validation
npm install multer express-validator

# Install utilities
npm install axios morgan helmet compression

# Install dev dependencies
npm install -D nodemon eslint

# Create .gitkeep files
New-Item uploads\.gitkeep -ItemType File
New-Item logs\.gitkeep -ItemType File

# Create config files
New-Item .env.example -ItemType File
Copy-Item .env.example .env
New-Item nodemon.json -ItemType File
New-Item src\server.js -ItemType File

# Update package.json scripts
npm pkg set scripts.dev="nodemon src/server.js"
npm pkg set scripts.start="node src/server.js"

cd ..
```

## 🔧 Fixes Applied

### **Issue 1: PowerShell File Creation**
**Problem:** `cat > file << 'EOF'` not working in PowerShell  
**Solution:** Used `New-Item` and manual file editing

### **Issue 2: Tailwind Init Failed**
**Problem:** `npx tailwindcss init -p` throwing errors  
**Solution:** 
- Uninstalled conflicting versions
- Installed specific working versions:
  - `tailwindcss@3.4.1`
  - `postcss@8.4.35`
  - `autoprefixer@10.4.18`

### **Issue 3: PostCSS 500 Error**
**Problem:** `index.css` causing 500 server error  
**Solution:**
- Simplified `index.css` to basic Tailwind imports
- Fixed `postcss.config.js` format
- Removed `@layer` directives temporarily

### **Issue 4: VSCode Linting Errors**
**Problem:** TypeScript errors in `.js` files  
**Solution:** Ignored (these are harmless warnings, don't affect runtime)
